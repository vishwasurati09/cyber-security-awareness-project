# Cyber Security Awareness & Risk Analysis System

This is an academic web application developed using Python and Flask, focused on
cyber security awareness and basic risk analysis.

## Project Overview
The system analyzes user cyber security behavior through a simple questionnaire
and categorizes the risk level as Low, Medium, or High. It also educates users
about common cyber attacks, security tools, cyber laws, and best practices.

## Features
- Cyber risk analysis (Low / Medium / High)
- Awareness of common cyber attacks
- Information about cyber security tools
- Cyber laws and do’s & don’ts
- Hacker-style terminal user interface

## Technologies Used
- Python
- Flask
- HTML
- CSS

## Domain
Cyber Security

## How to Run the Project
1. Install Python
2. Install Flask using `pip install flask`
3. Run the application using `python app.py`
4. Open browser and go to `http://127.0.0.1:5000`
